# 八项质检卡

> 「我看着挺好的」不是质检，是愿望。
> 质检的意思是：**把「好不好」拆成八个能具体回答的问题，每个都写下你在这张图上看到了什么。**

---

## 一、为什么要分八项

因为「这张图有没有问题」是个无法回答的问题 —— 太大了，大脑会自动跳过。

但「这张图里，左手大拇指在掌的哪一侧」是个能立刻回答的问题。

拆开的另一个好处：**你能定位到该修哪里**。如果说「人体有点怪」，你不知道从哪儿下手；如果说「contact 项不过，右手拿伞的握法像悬浮」，你就知道要修的是手和伞柄的接触点。

---

## 二、八项定义

每一项都要回答两件事：**看到了什么** + **判 pass / fail / na**。

### 1 · anatomy 人体结构

- 关节有没有反向弯折、比例有没有失控
- 肩→肘→腕这条线通不通
- 手指数量、长短、关节位置（尤其频繁崩的：拇指、小指、食指第三节）
- 脖颈与肩的连接、头部倾斜时的下颌线
- 站立时的重心落点

**常见崩法**：手指数错、拇指长在手背侧、手臂像面条、脖子过长、小腿比大腿长。

### 2 · contact 接触关系

> 这一项最容易被忽略，但它是「AI 感」的最大来源。

- 手是不是真的**贴**在物体上（接触点有没有缝隙 / 有没有穿模）
- 握东西时手指是否**包住**了截面
- 坐着的屁股有没有真的压到椅子
- 两个人拥抱时衣服有没有互相压陷
- 脚有没有踩实地面（还是浮着）
- 戴在身上的东西（眼镜、耳环、戒指）是否贴合

**常见崩法**：手握杯子像插在杯子里、脚悬空 5cm、帽子浮在头顶、两个人重叠却互不挤压。

### 3 · objects 物件完整性

- 道具形状前后一致吗（这一格是圆的，下一格变方的）
- 数量对不对（桌上三本书变两本）
- 遮挡关系对不对（该在前面的被压住了）
- 小字、纹理、图案有没有糊成一团
- 结构性物件（椅子、门、窗）的透视对不对

**常见崩法**：杯子把手消失、书页方向反、椅子腿数量异常、背景物体融化。

### 4 · faces 面部

- 与角色脸三特征是否吻合（眼皮、眉形、下颌）
- 表情是否对应这一格该有的情绪
- 双眼是否对称（不是要求完美对称，是不能一只大一只小到离谱）
- 视线方向是否符合剧本
- 牙齿、舌头、口腔有没有画成怪物

**常见崩法**：眼睛高低不一、笑容裂到耳根、瞳孔方向飘、侧脸变正脸。

### 5 · linework 线条

- 外轮廓与内部线的粗细有没有层次
- 头发是不是成组的块，而不是一根根碎线
- 衣褶是否只出现在该被挤压的地方
- 有没有莫名其妙的高光、噪点、雾面质感
- 该留白的地方有没有被塞满细线

**常见崩法**：全图一个线宽、头发像面条、衣服上有无意义的放射褶皱、皮肤上有油光。

### 6 · background 背景

- 背景密度是否匹配景别（特写该简，远景该有信息）
- 透视是否与人物一致
- 有没有不该出现的东西（凭空多一张桌子）
- 场景是否与前后的格子对得上
- 该省略的地方省略了吗

**判断标准不是「画得细不细」，是「有没有干扰主体」和「有没有交代地点」。**
没背景也不是错 —— 但要在记录里写清楚：是**有意省略**，还是**画漏了**。

### 7 · continuity 连续性

- 同一角色在这一格与上一格：发型、服装、配饰、伤痕一致吗
- 道具的位置和状态与上一格接得上吗
- 人物在画面里的左右关系有没有无理由翻转
- 光源方向是否统一（上一格左窗光，这一格右窗光就是错）
- 时间（早/中/晚）与天气是否连贯

### 8 · lettering 文字

> 如果用了「图字分离」，这一项查的是**叠完字之后**的成品。

- 文字有没有压到脸、压到关键手部/道具
- 气泡尾巴指向是否唯一、有没有穿过别人
- 有没有跳读风险（非连续气泡同列近邻）
- 文字预留面积是否 ≤ 格面积 38%
- 错别字、断行是否合理（不要把一个词拆成两行）
- 字号是否统一（同一页里不该忽大忽小）

## 三、三个倍率，各看什么

出完一页，用三个倍率各看一遍。**三个都要看，不能只看一个。**

| 倍率 | 看什么 | 为什么必须看 |
|---|---|---|
| **缩小到 25%** | 整体节奏：大格位置、气泡分布、黑白灰关系、读序 | 模拟读者在地铁上刷到这一页的第一眼 |
| **100%** | 主要问题：脸、手、道具、文字 | 日常阅读距离，绝大多数问题在这一档暴露 |
| **放大到 200%** | 细节：指节、睫毛、线条毛刺、文字描边 | 决定「这张能不能交付」而不是「能不能看」 |

> 只看 100% 是最常见的偷懒 —— 整体节奏的问题在 100% 看不出来，细节问题在 25% 也看不出来。

---

## 四、pass / fail / na 的使用规则

| 判定 | 什么时候用 | 怎么写 |
|---|---|---|
| **pass** | 该项看了，没问题 | 必须写一句**具体观察**，不是打勾 |
| **fail** | 该项看了，有问题 | 写清「在哪、什么样、往哪个方向改」 |
| **na** | 该项**在物理上看不见** | 写清为什么看不见（如「被椅子挡住」） |

### 三条禁令

1. **不许全填 pass**。全 pass 的记录等于没查。
2. **不许用 na 逃检**。na 只用于「确实不在画面里」，不用于「懒得看」。
3. **不许把 fail 写成 pass**。没修完就是 fail，修完要**重新看一遍**再改判。

### 合格的 pass 记录长这样

```markdown
- anatomy: pass —— 两人均为七头身，肩肘腕连线自然，
  女主左手小指略细但仍在合理范围
- contact: FAIL —— 男主右手与杯身之间有一条 4px 的缝，
  手指没有包住杯壁的弧面，像插进杯里
- faces: pass —— 男主眼皮平直、眉尾不收尖、下颌方而转角软，与 01 页一致
```

### 不合格的记录长这样

```markdown
- anatomy: pass
- contact: pass
- faces: pass
（全部一行一个 pass，没有一个字在描述这张图）
```

## 五、修正顺序（别一上来就补细节）

发现问题后，按这个顺序修，**顺序错了会白干**：

```
1. 结构 →  人体、接触、遮挡、透视
2. 表情 →  脸、视线、情绪
3. 线条 →  轮廓层次、头发成组、衣褶归位
4. 背景 →  密度、透视、必要信息
5. 细节 →  纹理、光效、装饰
```

**为什么不能倒着来**：你在第 5 步磨的细节，可能在第 1 步改结构时全部废掉。

---

## 六、修不动就停（三振规则）

同一格、同一构图，修到第 3 次还不解决：

- **停手**，不要再修第 4 次
- 记录：试过什么、为什么不行、最后怎么处理
- 退回改：格数 / 镜头 / 台词量（三选一）

修到第 3 次还不行，问题一定不在画上。

## 七、质检记录模板（直接抄）

```markdown
## 第 03 页 · 质检

**倍率**：25% ✓ / 100% ✓ / 200% ✓

| 项 | 判定 | 观察 |
|---|---|---|
| anatomy | pass | 两人七头身，肩肘腕连线自然 |
| contact | fail | 男主右手与杯身有 4px 缝隙，未包住弧面 |
| objects | pass | 桌上两只杯、一本本子，与 02 页一致 |
| faces | pass | 女主表情对应「压抑的惊讶」，与表情集 03 号吻合 |
| linework | pass | 外轮廓粗于内线，头发成 6 组块，无明显噪点 |
| background | pass | 有意省略背景，仅留窗框三条线，符合近景需要 |
| continuity | pass | 深蓝圆领T一致，光来自左侧，与 02 页同向 |
| lettering | fail | 格2 两个气泡同列近邻，有跳读风险 |

**待修**：1) 右手接触点 2) 格2 气泡下移 60px 或拆格
**复检**：修完重新看 100% 与 200%
```
