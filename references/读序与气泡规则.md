# 读序与气泡规则

> 画得好不好，读者会原谅。读得乱不乱，读者直接划走。
> 这一份管的是「读者的眼睛接下来会往哪儿走」—— 它比画功更容易翻车，也更容易检查。

---

## 零、先定翻页方向（不定就别往下做）

| 风格 | 方向 | 适用 |
|---|---|---|
| **国漫 / 条漫**（默认） | 左 → 右，上 → 下 | 国内平台、小红书、公众号 |
| 日漫仿作 | 右 → 左，上 → 下 | 明确要日漫味时 |

**铁律：一本书只能有一种方向。** 混着来的书，读者第三页就会读反。

定了方向，下面所有规则都按这个方向算。下文默认「左→右」。

---

## 一、两段式盲读（最便宜、最有效的质检）

### 核心思路

**先当读者，再当作者。顺序不能反。**

一旦你先看了正确的分镜编号和台词顺序，你的眼睛会自动把图「脑补成对的」——这叫确认偏误，谁都逃不掉。

### 操作

**第一段：裸读**

1. 把分镜稿上的格编号、读序引导线全部关掉，只留画面
2. 假装自己是第一次看的读者，在心里读一遍
3. 记下三件事：
   - 我的眼睛**第一眼**落在哪
   - 我**下一句**会去读哪个气泡
   - 有没有哪一格我**停住了、找不到出口**

**第二段：对照**

4. 这时候才把台词顺序、编号、你的设计意图拿出来
5. 对一遍：我预测的顺序 ≈ 我设计的顺序吗？

### 判据

| 情况 | 结论 |
|---|---|
| 预测顺序与设计一致 | 过 |
| 差一个位置 | 可接受，但要记下原因 |
| 完全读乱 / 有格子找不到出口 | **打回改分镜**，不是改台词 |

### 记录格式（写进产出里）

```markdown
【裸读记录 · 第 3 页】
- 第一眼落点：右上格的脸
- 预测读序：格1 → 格3 → 格2（我原本设计的是 1→2→3）
- 卡住的地方：格2 的气泡太小，被格3 的大脸抢走了注意力
- 处理：把格2 气泡放大一号，格3 的脸往下挪 40px
```

> 这一段宁可写得啰嗦。它记录的是**读者真实的眼睛**，不是你的设计意图。

## 二、11 条核对面（逐条过，别跳）

每页出完，按这 11 条过一遍。

| # | 核对面 | 不合格长什么样 |
|---|---|---|
| 1 | 第一句从**上/左**进入吗 | 读者从右下角开始读 |
| 2 | 有没有**跳读**风险（见第四节） | 同一竖列里第 1 句和第 3 句贴得很近 |
| 3 | 同一段对话**成组**了吗 | 三个人的话打散在整页，读者来回折返 |
| 4 | 视线有没有**大回头** | 读完右下又要回到左上 |
| 5 | 气泡**尾巴**是否指向唯一的说话人 | 一根尾巴横跨三格、或者悬空没指人 |
| 6 | 脸、视线、手部动作是否与读序**同向** | 人物看着左下，气泡却在右上 |
| 7 | 时空切换有**锚点**吗 | 突然从教室到走廊，读者不知道过了多久 |
| 8 | 上一格到下一格的**出口**顺畅吗 | 上一格的动作说到一半，下一格已经换了场景 |
| 9 | 大格 / 留白的**位置**服务于情绪吗 | 全页一样大，读者没有重点 |
| 10 | 话题边界与**格边界**对得上吗 | 两个话题挤在一格里 |
| 11 | 页面末端有没有**翻页的钩子** | 最后一格是「于是他们回家了」，读者没有翻的动力 |

## 三、气泡五条硬规则

这五条是**可以机械判断**的，不是审美问题。做完一页，五条必须全过。

### 规则 1 · 气泡不压脸

气泡矩形与任何人物的脸部矩形不相交。

> 脸被遮住一角，读者就读不到表情，那一格的情绪就白画了。
> 实在放不下，就**改镜头**（拉远、换角度），不要硬压。

### 规则 2 · 尾巴不穿人、不穿物

尾巴线段不得穿过：
- 其他人的脸部区域
- 关键手部（正在做动作的那只）
- 关键道具（正在被递、被拿、被看的东西）

> 尾巴穿过别人的脸，读者会误认说话人 —— 这是最低级也最致命的错。

### 规则 3 · 尾巴长度 ≤ 160px

尾巴是短短的三角形，不是天线。

- 超过 160px 就开始像两根筷子
- 超过 260px 说明**气泡放错位置了**，该把气泡挪到说话人旁边
- 移动气泡永远比拉长尾巴好

### 规则 4 · 相邻气泡不许「左→右回跳 + 纵向重叠」

后一句的气泡如果在更靠右的位置，同时它的纵向范围又与上一句重叠，读者会把它俩看成一组。

**改法（三选一）：**
- 拉开纵向距离，让它们分属不同的「行」
- 把后一句换个位置
- 拆成两格

### 规则 5 · 顺序与位置同向

气泡的**排列顺序**必须等于**读序**。

不能出现「按台词表是第 2 句，但画面上它排在左下角、看起来像第 3 句」。

> 如果为了构图必须错位，那就改构图。**顺序是硬约束，位置是软约束。**

## 四、跳读检测（专业漫画最常犯的错）

### 什么叫跳读

同一竖列里，第 1 句和第 3 句靠得很近，第 2 句在别处。读者的眼睛会**跳过第 2 句直接读第 3 句**，然后回头补，节奏全乱。

### 判据（可以直接算）

对每一组「非连续」的气泡对 A（第 i 句）和 C（第 j 句，j ≥ i+2）：

```
同列判定：A 与 C 在水平方向上范围重叠
间距判定：gap(A,C) < gap(A, 下一句) × 0.65
      且 gap(A,C) ≤ max(32px, 页面宽度 × 0.14)
两条都满足 → 跳读高风险，必须改
```

### 改法

| 症状 | 药方 |
|---|---|
| 两句贴太近 | 拉开纵向间距，或把中间那句移到同侧 |
| 中间那句离太远 | 把中间那句拉回来，靠近它该在的位置 |
| 三句挤在同一列 | 拆格，或者换一个版式（用眼神链、阶梯式） |
| 改位置改不动 | 说明这一格话太多 —— **回去砍台词** |

## 五、文字量控制（两条硬指标）

### 指标 1 · 文字预留面积 ≤ 格面积的 38%

一格如果一半以上被气泡占满，画面就死了。

超了怎么办，按顺序试：
1. 删台词（最好使）
2. 把一句长台词拆到相邻两格
3. 把这一格改成两格
4. 换镜头（拉远给气泡腾地方）

**注意顺序：先砍字，后改格，最后才是改镜头。** 大多数人反过来做，越改越挤。

### 指标 2 · 人物脸高 ≥ 40px（以 1024 宽的页面计）

低于 40px，表情就画不出来，读者看不见情绪。

如果一格要放很多人又都要有表情 —— 那说明这一格**不该放这么多人**。

## 六、三振出局（防无限烧图）

同一个格，同一个构图，修了 **3 次**还没解决 —— **停手**。

不许再修第 4 次。必须退回去改这三样之一：

1. 格数（拆格 / 并格）
2. 镜头（换景别 / 换角度）
3. 台词量（砍 / 拆 / 换说法）

### 为什么

因为修到第 3 次还没解决，说明**问题不在画上，在分镜上**。继续修图只是把钱烧给同一个错误。

停下来的时候，把这三件事记下来：
- 试过哪三种改法
- 各自为什么不行
- 最终选了哪种结构性修改

> 这三条记录比那张图值钱 —— 下次遇到同类问题可以直接跳过试错。

## 七、常见读序事故对照表

| 事故 | 现场长什么样 | 一句话药方 |
|---|---|---|
| 双人对话来回折返 | 两人各说三句，气泡左右左右跳 | 把每人的话**成块**排列，不要交替 |
| 旁白抢戏 | 旁白框横跨整页顶部，读者先读它 | 旁白放下方或侧边，让画面先进 |
| Q 版抢主戏 | Q 版小人太亮太满，盖过正式版 | Q 版面积 ≤ 主格 1/5，明度压低 |
| 大格无出口 | 满版大图，右下角什么都没有 | 右下角留一个反应或一句收尾 |
| 翻页断气 | 末格是完结式陈述 | 换成一个未答的疑问 / 一个动作的起手 |
| 三格同大小 | 全页一样大，节奏平 | 至少一格明显更大或更窄 |
