# 章节扉页（每章的第 1 页）

一章正文之前，先给一页大标题。**它不算正文页**，编号记作 `P00`。

作用有三个：读者翻到这儿知道"新的一章开始了"；连载时这一页就是封面缩略图；手机竖屏刷的时候，大字标题比任何一格画面都容易被记住。

---

## 一、四种版式，先选一个

一本书**只用一种**，别换。换版式读者会以为换了一本书。

| 版式 | 长什么样 | 什么时候用 | 要不要生图 |
|---|---|---|---|
| `vertical` | 纸纹底，标题竖排在右，左侧红竖线压「第X章」，左下角一个巨大的章号水印 | 日漫 / 国漫常规，最稳，零成本（默认） | 不用 |
| `split` | 上半张画面（占 56%），下半米色纸，标题横排居中 | 想要一页"像书的扉页"，且手里有合适的气氛图 | 要一张图 |
| `center` | 纸纹底，标题居中，上下双横线 + 细边框 | 文艺、慢节奏、情感章节 | 不用 |
| `band` | 整页画面压暗，中间一条深色横带压白字标题，上面一条红窄条压章号 | 冲击力强，适合转折章、高潮章 | 要一张图 |

**默认建议 `vertical`。** 理由是它不花一次生图、每章都能保证同一种气质，而且大字竖排在手机竖屏上最好看。

---

## 二、图从哪来（只有 split / band 需要）

三条路，按优先级：

1. **单独生一张无格气氛图** —— 最好。提示词里加 `single illustration, no panel borders, no speech balloons`，画"这一章要发生的那件事的物证"：空教室、两副餐具、桌上的平板。
2. **从正文里裁一整格** —— 次好。用 `--crop x,y,w,h` 精确框出**一整格**，比例尽量接近 `1080:860`。
3. **直接拿正文整页当底** —— **不要**。正文页有三四条分格线，压成横幅后会出现两条黑线横穿画面，一眼假。

> 这一条是实测踩出来的：第 2 章用整页 P01 做底，图区里横着两道分格线，像被切断拼接。换成裁下格（平板特写）立刻干净。

裁一格的坐标怎么找：看 `panels.json`（分格检测结果），或者直接把图缩到 25% 目测。

---

## 三、文案就三样，别加第四样

| 位置 | 内容 | 例子 |
|---|---|---|
| 章号 | `第X章`（默认自动转中文数字） | 第一章 |
| 章名 | 这一章的标题，直接取原文 `##` 那一行 | 九月的第一个bug |
| 英文行 | 可选。书名英文 + 章号，或一句引子 | YOUR FORMULA, MY DRAWING · CH.01 |

**不要写剧情简介**，那是章末预告页的活。扉页只有标题。

章名太长（超过 10 字）时脚本会自动缩字号；再长就砍，扉页标题超过 12 字就不像标题了。

---

## 四、字体：为什么必须是「思源宋体 Heavy + 拉丁回落」

标题用 `C:/Windows/Fonts/Source Han Serif SC Heavy (TrueType).ttf` —— 笔画粗、有锋芒、横细竖粗，放大到 150px 以上非常好看，是实体书标题的调子。

**坑：这个字体的子集缺 ASCII。** 数字 `1`、空格、`·`、`.`、`/` 全部渲染成 ☒ 豆腐块。第一版就是这个死法：`第☒1☒章`、`YOUR☒FORMULA`。

所以脚本里做了一层分派：

- **非 ASCII（中文）** → 思源宋体 Heavy
- **ASCII（数字、空格、标点、英文）** → `NotoSerif-Bold.ttf`（同族衬线，视觉几乎无缝）

换成 `--face sans` 时，中文走雅黑粗，拉丁自动换成 `NotoSans-Bold`。`--face round` 用等线粗体，偏圆润。

> 自己接别的中文字体时先测这五个字符：`九 1 b 空格 ·`。有一个出方块，就必须配拉丁回落。

## 五、命令

```bash
# 竖排刊头（默认，零生图）
python scripts/make_title.py --out final/P00.png --no 1 \
  --title "九月的第一个bug" --en "YOUR FORMULA, MY DRAWING · CH.01" --ghost

# 上图下文：从正文页里裁一整格
python scripts/make_title.py --page art/P01.png --crop "0,975,1080,560" \
  --out final/P00.png --no 2 --title "公共课的同桌" \
  --en "CH.02 · A SEAT BY THE WINDOW" --style split --dim 22

# 横带冲击版
python scripts/make_title.py --page art/P15.png --out final/P00.png --no 12 \
  --title "你的人生不需要公式" --style band --dim 35

# 居中文艺版
python scripts/make_title.py --out final/P00.png --no 7 --title "雨天的伞" \
  --style center --ghost --accent "#2F5D50"
```

常用参数：

| 参数 | 用途 |
|---|---|
| `--style` | `vertical` / `split` / `center` / `band`，默认 auto（有图→split，无图→vertical） |
| `--no` | 章号，脚本自动转中文数字（12 → 十二） |
| `--en` | 底部英文行，过长自动缩字号 |
| `--ghost` | 背景压一个大号章号水印 |
| `--crop` | `x,y,w,h` 先从底图裁一整格 |
| `--focus` | 裁切焦点 `top/center/bottom` |
| `--dim` | 底图压暗 0-100，有图时 22~40 够用 |
| `--accent` | 强调色，默认 `#B33A2B` 砖红 |
| `--paper` | 纸色，默认 `#F4EFE4` |
| `--face` | `serif` / `sans` / `round` |

输出尺寸默认 `1080×1536`，与正文页一致；要别的比例用 `--w/--h`。

## 六、五个坑

1. **标题顶满整页** —— 竖排超过 10 字时字号会缩到 130 以下，气势就没了。宁可砍字。
2. **数字豆腐块** —— 见第四节。别用没回落的中文字体。
3. **拿正文整页做底** —— 分格线横穿画面。见第二节。
4. **章号压到深色带上** —— `band` 版式里章号必须落在实色窄条上，落在画面上就会被背景吃掉。
5. **水印抢戏** —— `--ghost` 的章号数字不透明度只有 20~30，如果看着太明显，去掉它，别调大。

---

## 七、和整体流程的关系

```
P00 扉页   →   P01 正文第 1 页   →   …   →   Pn 章末预告
```

- 扉页**不进**叙事节奏，版式疲劳的三条硬约束（连两页不同版式等）**不适用**于它
- 扉页不计入总页数的节奏配比
- 一本书的扉页版式、纸色、强调色固定，跟正文画风一起写进「全书样式锁」

```jsonc
"book_style": {
  "title_style": "vertical",
  "paper": "#F4EFE4",
  "accent": "#B33A2B",
  "face": "serif"
}
```

下一章直接读这份锁，不用再问。
