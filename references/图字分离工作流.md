# 图字分离工作流

> 让模型画画，让代码写字。
> **画会错，字不会。**

---

## 一、为什么要把字和画拆开

### 三个躲不掉的现实

1. **图像模型写中文必错。** 笔画多一点、少一横、把「姝」写成「妹」—— 它是在「画出看起来像字的图形」，不是在打字。
2. **字画在一起，改一个字要重画整页。** 台词改一个标点，脸就得重新生成一次，脸一变整页废。
3. **字画在一起，位置没法校验。** 气泡压没压脸、尾巴指向谁、读序乱不乱 —— 全靠肉眼，且只能靠肉眼看一遍。

### 拆开之后

| | 字在画里 | 图字分离 |
|---|---|---|
| 错字 | 常有，且难发现 | **零**（代码写的字） |
| 改台词 | 重新生图（贵、脸会变） | **秒级重排** |
| 气泡位置 | 无法校验 | **脚本可算、可报警** |
| 分层编辑 | 做不到 | 图一层、字一层，后期还能改 |
| 成本 | 一次到位 | 多一个组版步骤 |

## 二、两种模式，先选一种

### 模式 A · 整页直出（快，适合草稿与试风格）

- 一个提示词生成一整页带字漫画
- 优点：一步到位，快
- 缺点：字可能错、改字要重画
- **适合**：试画风、给客户看构图、快速出量

### 模式 B · 图字分离（稳，适合成品）

- **第一步**：生图时明确「不要任何文字/气泡/边框」，只留白色禁区
- **第二步**：用脚本把中文气泡叠上去
- 优点：字 100% 正确、可校验、可改
- **适合**：要交付的成品、要连载的长篇

> 建议：**模式 A 定风格，模式 B 出成品。**
> 一册里可以混用，但同一页不要混。

---

## 三、模式 B · 第一步：出「干净的画」

### 提示词必须写死这几句

```
OUTPUT: 独立的漫画画面，不要任何文字、对话气泡、边框、水印、可见辅助线。
        气泡预留区保持自然留白，脸和关键动作不要被遮挡。
```

英文版（直接用）：

```
No text, no speech bubbles, no lettering, no borders, no watermark, no visible guide marks.
Leave the planned balloon areas naturally empty and keep faces and key actions unobstructed.
```

### 同时要告诉它「哪里留白」

在你的生图提示词里，补一句坐标或方位描述：

```
Leave an empty area at the upper-left of the first panel (about 1/3 width, 1/4 height) for a balloon.
```

或者在分格描述里写「该格右上留白」，比坐标更好使。

### 常见失误

| 失误 | 后果 | 修法 |
|---|---|---|
| 忘了写 no text | 模型自己画了一堆乱码字 | 补上，重生成 |
| 留白区太小 | 气泡放不下，只能压脸 | 留白写大一点（宁大勿小） |
| 留白区在画面正中 | 把主体切成两半 | 靠边留，别留在视觉中心 |
| 让模型「画个空白气泡」 | 它会画一个歪的、带字的 | 一个字都别提，只说留白 |

## 四、模式 B · 第二步：把字叠上去

### 4.1 写一份气泡表

保存为 `page01-bubbles.json`：

```json
{
  "page": { "w": 1024, "h": 1536 },
  "defaults": { "size": 30, "min_size": 19, "line_gap": 1.4, "padding": 0.75, "max_text_width": 300 },
  "keepout": [[380, 180, 240, 240]],
  "bubbles": [
    {
      "speaker": "苏念一",
      "text": "你怎么会在这里？",
      "style": "round",
      "x": 96, "y": 96,
      "tail": { "to": [470, 300] },
      "face": [380, 180, 240, 240]
    },
    {
      "speaker": "陈序之",
      "text": "画板落教室里了。你呢，这么晚了还不回去？",
      "style": "round",
      "x": 620, "y": 430,
      "tail": { "to": [300, 980] }
    },
    {
      "speaker": "旁白",
      "text": "十一月的风，把走廊尽头的窗吹得咣当响。",
      "style": "caption",
      "x": 60, "y": 1420
    }
  ]
}
```

### 4.2 字段速查

| 字段 | 作用 | 说明 |
|---|---|---|
| `text` | 台词正文 | 支持 `\n` 手动断行 |
| `style` | 气泡样式 | 见下表 |
| `x` / `y` | 左上角坐标 | 省略则按 `--auto-layout` 自动找位 |
| `w` / `h` | 强制尺寸 | 一般不用，省略时按文字自动算 |
| `tail.to` | 尾巴指向 | 填**嘴部坐标**，脚本会自动停在脸外 |
| `face` | 说话人脸部矩形 | 用于「气泡不压脸」和「尾巴停脸外」 |
| `size` | 单独指定字号 | 喊叫可放大，呢喃可缩小 |
| `align` | `center`（默认）/ `left` | 旁白常用 left |
| `keepout` | 保护区数组 | 关键手部、关键道具，气泡和尾巴都不会碰 |

### 4.3 六种气泡样式

| style | 形状 | 用在哪 |
|---|---|---|
| `round` | 圆角矩形 | **默认**，正常对话 |
| `oval` | 椭圆 | 弱声、犹豫、气声 |
| `thought` | 椭圆 + 三个递增圆点 | 内心独白（不想让人听见） |
| `shout` | 爆炸锯齿 | 喊叫、受惊、爆发 |
| `caption` | 直角方框，无尾巴 | 旁白、时间地点说明 |
| `bare` | 无底色无边框 | 拟声词、手写字 |

### 4.4 跑脚本

```bash
python scripts/lettering.py --page page01.png --spec page01-bubbles.json --out page01-final.png
```

加 `--auto-layout` 可以让脚本自动找位置（你没给坐标时）：

```bash
python scripts/lettering.py --page page01.png --spec page01-bubbles.json --out page01-final.png --auto-layout
```

### 4.5 看报告

脚本会同时生成 `page01-final.report.json`，并当场打印警告：

```
✓ 已合成 page01-final.png
  气泡 3 个，画布 1024×1536
  ⚠ 2 条校验警告：
    - [气泡 1] 气泡离说话人约 625px，尾巴已被截到 160px。
                建议把气泡挪到人物附近（160px 内），否则读者要靠猜
    - [0→2] 第 1 句与第 3 句同列且靠得比第 2 句更近（18 < 340），
            读者会跳读中间那句；请调整行/分组或拆格
  报告：page01-final.report.json
```

**看到警告就改，不要无视。** 每一条警告都对应真实读者会踩的坑。

### 4.6 脚本会自动做的事

- 中文自动换行 + **避头尾**（标点不落行首，开引号不落行尾）
- 字号自适应（放不下就逐磅缩，缩到下限会提示你砍字）
- 椭圆/爆炸形自动放大外框（因为内接空间更小）
- 尾巴尖端自动停在脸外 4px，不戳进脸里
- 尾巴超长自动截到 160px 并警告
- 尾巴不穿其他人的气泡、不穿保护区
- 检测「左→右回跳」「非连续同列近邻」两种跳读风险
- 输出气泡坐标报告，方便复用到下一页

## 五、把两页连起来：完整的一次作业

```bash
# 1. 出画（在生图工具里用这个提示词，明确不带字）
#    → 得到 page01.png（干净画面，一块留白）

# 2. 写气泡表
#    → page01-bubbles.json

# 3. 组版
python scripts/lettering.py --page page01.png --spec page01-bubbles.json --out page01-final.png

# 4. 看报告，改警告，重跑（秒级，不烧图）

# 5. 八项质检（重点查 lettering 那一项）

# 6. 进对照看板
python scripts/build_board.py --data 第01章.json --out 第01章-对照台.html
```

## 六、什么时候别用图字分离

说句实话，它不适合所有情况：

| 情况 | 建议 |
|---|---|
| 只想快速试一个画风 | 用模式 A，别折腾 |
| 单张插画 / 封面 | 用模式 A（字少，且通常后期加标题） |
| 要做 20 页以上的连载 | **必须**模式 B |
| 台词密集的对话页 | **必须**模式 B（否则字必错） |
| 拟声词很多的动作页 | 模式 B 但把拟声词用 `bare` 样式，或干脆留给后期手写 |

## 七、字体说明

脚本默认按顺序找字体：

```
C:/Windows/Fonts/msyh.ttc      微软雅黑（首选，中文最稳）
C:/Windows/Fonts/simhei.ttf    黑体
C:/Windows/Fonts/simsun.ttc    宋体
macOS: PingFang.ttc
Linux: Noto Sans CJK
```

想换字体，在气泡表的顶层加 `"font": "路径"` 即可。

> **交付前提醒**：用商业字体前确认授权。免费可商用的中文字体：思源黑体、阿里巴巴普惠体、站酷系列（部分）。
