# 文字三模式

漫画里的字，是最容易毁掉一页的东西。同一个画面，字有三种上法，各有各的代价。

**开工时问清楚，别默认。** 用户说「你看着办」才走 B。

---

## 一、先搞清一件事：模型不是在打字

模型画中文字，本质是**画出一堆长得像字的图形**。它没有字符表，没有字形轮廓，没有笔画顺序。

这带来三个必然结果：

1. **形近必错**：姝→妹、己→已、末→未、拨→拔、即→既、刺→剌、晴→睛
2. **笔画必丢**：复杂的字（赢、蘸、翻、戳、巍）掉笔画是常态，简体的「纟」「讠」「辶」尤其容易糊
3. **串行必发生**：一句话里中间几个字被相邻气泡的字顶替，或者干脆重复

所以「让模型写字」不是做不到，是**你要接受一个错字率，并且准备好查和改**。

---

## 二、三模式对照

| | A · 全交模型 | B · 先出后改 | C · 全后加 |
|---|---|---|---|
| 字从哪来 | 生图提示词 | 模型先画，错的覆盖 | 脚本叠加 |
| 画面自带气泡 | 是 | 是（局部有补丁） | 否（禁字令） |
| 错字风险 | 高 | 中 | 零 |
| 改一句台词 | 重画整页 | 重画整页 / 补丁叠字 | 秒级重排 |
| 气泡位置 | 模型定，常压脸 | 模型定，可用补丁挪 | 脚本算，可校验 |
| 出图次数 | 1 次（错则 2~4 次） | 1 次 + 局部补丁 | 1 次 |
| 一页平均耗时 | 1~4 轮出图 | 1 轮 + 5 分钟补丁 | 1 轮 + 3 分钟组版 |
| 适合 | 短句、拟声、要手感 | 批量长篇、能忍补丁 | 交付、连载、对白密集 |

## 三、模式 A · 全交模型

### 提示词怎么写

**不能写禁字令。** 改成明确的「字画指令」，并且把台词编号对齐到格子。

```
Chinese speech balloons are part of the artwork.
Draw each balloon as a clean white rounded shape with a thin black outline
and a short tail pointing at the speaker's mouth.
Write the Chinese dialogue EXACTLY as given, in a legible hand-lettered
Chinese font, horizontal, left to right, one phrase per balloon:

  panel 1 — 苏念一: 「哎，你也是这个班的？」
  panel 2 — 陈序之: 「嗯。」

Do not add any other text anywhere on the page: no watermark, no signature,
no page number, no author name, no panel labels, no English.
```

### 三条铁律

**铁律一：一句话一气泡，短句优先。**

超过 12 个字，模型几乎必然断错。宁可拆成两个气泡，也不要写一句长的。

| 别写 | 改写 |
|---|---|
| 「你的字体大小不一致，标题用了18号，正文是14号，但第二页的正文是13号」 | 拆成三个气泡：「字体大小不一致。」／「标题 18 号。」／「第二页正文 13 号。」 |

**铁律二：台词表和分格描述必须编号对齐。**

不编号，模型会把台词塞进任意一格，甚至塞进没有人的空镜格。

**铁律三：出图后逐字核对，不许目测。**

放大到 200% 看，一个字一个字念。**一句话里只要错一个字，这一格就不合格。**

### 逐字核对的顺序（省时间）

1. 先看**句数**对不对（少了/多了气泡就是漏了台词）
2. 再看**每句首尾字**（首尾错说明整句被替换）
3. 最后扫**中间的字**，重点盯这些高危字：

```
形近组：姝妹 己已 末未 拨拔 即既 晴睛 刺剌 戌戍 侯候 辨辩 蒙朦胧
繁笔组：赢 蘸 翻 戳 巍 蠢 霸 曦 繁 颤
偏旁组：纟（红绿细线） 讠（说话讲论） 辶（这过还进） 阝（那个都部）
常用虚词：的 了 着 就 都 也 还 又（最容易串行或重复）
```

### 不合格怎么办

| 症状 | 处理 |
|---|---|
| 1~2 个字错，气泡位置正常 | 转到模式 B，打补丁 |
| 整句被替换 / 串行 | 重出这一页 |
| 气泡画在人物脸上 | 重出这一页（改分格描述，把气泡位置写进 prompt） |
| 同一格修了 3 次还错 | **放弃模型画字，这一页改走 C** |

最后一条是硬规则。同一格修三次不成就说明模型对这格的字形没有稳定解，继续烧是在赌。

## 四、模式 B · 先出后改

模型照 A 的方式画字 → 查 → **只改错的那几格**。

### 补丁怎么做

```bash
python scripts/lettering.py --page 图.png --spec 补丁.json --out 改好.png
```

补丁 JSON：

```json
{
  "page": {"w": 1024, "h": 1536},
  "defaults": {"size": 30, "min_size": 20, "max_text_width": 360},
  "bubbles": [
    {
      "speaker": "苏念一",
      "text": "哎，你也是这个班的？",
      "style": "round",
      "x": 118, "y": 74,
      "cover": {"pad": 16, "blur": 6},
      "tail": {"to": [338, 428]},
      "face": [330, 380, 150, 170]
    }
  ]
}
```

`cover` 参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `box` | 无 | **显式指定要盖掉的矩形** `[x, y, w, h]`，填模型原气泡（含尾巴）的范围。模型画的气泡比新气泡大时**必须给这个** |
| `shape` | 跟气泡样式 | 覆盖块形状：`oval` / `round` / `caption` / `shout` |
| `pad` | 14 | 没给 `box` 时，按新气泡外扩多少像素 |
| `blur` | 6 | 羽化半径。0 = 硬边；6~8 最稳；超过 12 会把原黑边框糊成灰影 |
| `color` | `auto` | **默认取外圈中位色**，让补丁贴近背景。要纯白就写 `"white"` |

脚本的绘制顺序是两轮：先统一盖所有 cover 块，再画所有气泡。所以补丁不会互相吃掉对方的字。

### 关键：box 要给足

```json
"cover": {"box": [58, 56, 444, 388], "shape": "oval", "color": "auto", "blur": 6}
```

框要给到**包住原气泡的黑色边框和尾巴根部**。框小了，就会残留一道淡弧（原边框正好落在羽化带里），一眼就看出这里补过。

判断标准：**框的边缘要落在纯背景上，不能落在原气泡的边框上。**

### 什么时候不能打补丁

给了 `cover.box` 之后，补丁可以**既改字也改位置**——把原气泡盖掉，在别处重画。但有两条红线：

1. **白块不能压到人物脸和关键道具。** 压了就是一块明显的贴纸。
2. **白块面积不能超过原气泡的 1.6 倍。** 超过说明你想盖的东西不止一个气泡，这时候该重画那一页。

如果模型把气泡画在了人物脸上、或者画得比目标大两圈，优先**重画那一页**——在分格描述里把气泡位置写进去（`with a clean empty area at the top-left for a balloon`），比重画补丁干净。

判断标准很简单：**白块外扩后是否还在原气泡的白底范围内。** 在，放心补；不在，重画。

### 补丁的视觉痕迹

实话说，补丁一定能看出一点点：

- 白块边缘和原气泡边缘不重合 → 有一道浅浅的色阶线
- 羽化半径太小 → 硬边；太大 → 原来的黑边框糊成灰影

**最干净的做法是让白块略大于原气泡、羽化 6~8、并且把新气泡的黑边框画在原黑边框外侧 2~3px**，这样新边框正好压住旧边框的痕迹。

## 五、模式 C · 全后加

提示词里写死禁字令（`文字三模式` 只讲字，流程见 `图字分离工作流.md`）：

```
Absolutely no text in the artwork: no letters, no writing, no Chinese characters,
no speech balloons, no captions, no sound effects, no watermark, no signature,
no page numbers. Leave clean low-detail areas where balloons can be placed later.
```

然后：

```bash
python scripts/lettering.py --page 干净页.png --spec 气泡.json --out 成品.png
```

这条路的收益不只是「不错字」，是**台词可以随时改**。改一句重跑 3 秒，脸不变、构图不变、不用重新出图。

## 六、怎么选

```
要手感和拟声词？            → A
批量出长篇、错一点能忍？      → B
要交付、要改台词、要连载？    → C
```

### 按画风选（实测倾向）

| 画风类型 | 建议 | 原因 |
|---|---|---|
| 水墨 / 书法感 | **C** | 模型会把手写字画成墨团，且很难和后加水墨字融合 |
| 粗糙涂鸦 / 手绘速写 | A 或 B | 字本来就不规整，读不出错也像风格 |
| 赛璐璐 / 扁平矢量 | B | 气泡干净、字块清晰，错了补丁几乎看不出 |
| 厚涂 / 写实 | **C** | 写实画面的白气泡本来就突兀，后加反而更整洁 |
| 儿童绘本 / Q 版 | A | 字大句短，容错高，圆胖字体模型画得不错 |

## 七、给用户看的一句话

> **A 是「让模型签个名」，B 是「签错了涂改一下」，C 是「打印好再盖钢印」。**

三种都对，看你这一页是用来试的还是用来卖的。

## 八、实测数据（《你的公式我的画》第 2 章 · 16 页 25 句）

模式 A 真跑一遍的结果，给个准数：

| 指标 | 结果 |
|---|---|
| 台词总句数 | 25 句（每句 ≤12 字） |
| 逐字全对 | 24 句 |
| 出错 | 1 句（「送你箱子的人，是我室友」漏了「人」字） |
| 字准确率 | **96%** |
| 错字类型 | 漏字，不是形近字 |
| 首轮出图返工页数 | 6 / 16（37.5%），其中 1 页因为漏字、5 页因为场景漂移 |

### 结论一：短句的中文准确率比预期高得多

12 字以内的句子，模型几乎都能一字不差地写出来。**真正会出错的不是笔画，是"多字/少字"**——它会把一个不重要的虚词或量词吞掉。

所以核对重点是**数一遍字数**，不是逐个查笔画。

### 结论二：模式 A 真正的短板不是字，是场景

6 页返工里 5 页是场景漂的：

- 3 页把教室画成了**书架/图书馆**
- 1 页把室内画成了**户外校园**
- 1 页把教室画成了**客厅沙发**
- 1 页把插画画成了**照片**

原因：模式 A 的提示词里塞了大量台词和气泡位置，模型的注意力被吸到"画人 + 写字"上，对背景的把关松了。

**修法**：在每页 prompt 里单列一段 SETTING，把"是什么"和"不是什么"都写死：

```
SETTING — the whole chapter takes place inside ONE tiered university lecture hall:
stepped rows of wooden desks, tall windows along the right side, a projector screen
at the front, plain white walls. It is NEVER a library, NEVER bookshelves, NEVER a
cafe, NEVER a living room, NEVER outdoors. The same room must look identical on
every page.
```

再配一段 RENDER 锁防画风跑：

```
RENDER: identical painterly anime illustration style as every other page —
soft cel shading with visible painterly brushwork, crisp clean line art.
NOT a photograph. NOT a 3D render. NOT photorealistic.
```

加上这两段之后，重出的 6 页全部回到教室，画风也对上了。

### 结论三：长台词拆句是刚性前提

原稿里 3 句超过 12 字，全部拆成两泡之后才有了这个准确率。**不拆就是必错**，不是概率问题。

### 结论四：模式 A 的成本结构

| | 模式 A | 模式 C |
|---|---|---|
| 首轮出图 | 16 页 = 16 次 | 16 页 = 16 次 |
| 返工 | 6 页 = 6 次 | 0 次 |
| 组版/上字 | 0 | 16 次脚本（几秒） |
| 改一句台词 | 重出整页 | 3 秒重排 |
| 最后的样子 | 字是画面的一部分，最像手工漫画 | 字是贴上去的，最整齐 |

**结论：一页要改三次以上台词，就走 C。一次成型的，A 完全可用。**
