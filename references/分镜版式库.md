# 分镜版式库（68 种漫画分镜 · 凝练版）

> 来源：本机 `handraw-style` 技能 LAYOUTS.md 的 SB-001~SB-068 全套漫画分镜图型（Comic Storyboards）。
> 本文件把它们重新洗成 **6 个功能族 + 5 个用户可选项**，避免让用户面对 68 个编号发懵。
> 全部 68 种编号在本文末有总表，无遗漏、无重复。

---

## 一、为什么不能直接给用户 68 个编号

68 个编号是「素材库」，不是「选项」。让人从 68 个里挑版式，等于让人从 68 种螺丝里挑一颗拧上去——绝大多数人会在前 5 个里随便选一个，然后整套漫画的版式就僵死在规则网格上了。

所以本技能的做法是：**用户只做 1 次 5 选 1，AI 在幕后调度全部 68 种。**

---

## 二、用户面对的 5 个选项（生成条漫时问这一句）

开工前必须问，且**只问这一个**：

```
本册漫画的版式节奏，你想走哪一路？

1. 自动编排（推荐）—— 我按每页剧情节奏自己调度，整册有起伏，不会页页一个样
2. 稳 —— 叙事清晰优先，规则网格/四格起承转合为主，适合对白多、篇幅长的日常向
3. 燃 —— 动感冲击优先，对角切割/破框/满版大格为主，适合动作、冲突、高潮
4. 情绪 —— 留白与特写优先，超窄反应格/眼神链/骤停为主，适合心理戏、暧昧、转折
5. 花样 —— 形式感优先，闪回嵌套/手机聊天式/无边框为主，适合回忆、现代社交、章节头尾点睛

回复数字即可，不回复默认走 1 自动编排。
```

各选项对应的调度范围：

| 用户选项 | 主用族 | 可借调 | 整册占比建议 |
|---|---|---|---|
| 1 自动编排 | A+C 混合 | B / D / E / F 按剧情触发 | 见下方配比规则 |
| 2 稳 | A 稳（12 种） | C 组点缀 | A 70% + C 25% + E 5% |
| 3 燃 | B 燃（12 种） | A 组过渡 | B 50% + A 35% + C 15% |
| 4 情绪 | C 情绪（12 种） | A 组兜底 | C 55% + A 35% + D 10% |
| 5 花样 | E 花样（12 种） | A 组串联 | E 45% + A 40% + C 15% |

> ⚠️ 选 3「燃」或 5「花样」时，必须提醒用户：**这类版式连用会疲劳**，长篇建议改回自动编排。

### 自动编排配比规则（AI 内部执行，不展示给用户）

| 页面性质 | 用哪个族 | 占比 |
|---|---|---|
| 常规叙事 / 对白推进 | A 稳 | 约 60% |
| 情绪、沉默、转折 | C 情绪 | 约 25% |
| 高潮、冲突、追逐 | B 燃 | 约 10%（上限 15%） |
| 时间推移、同一空间多时刻 | D 时间 | 按需 |
| 回忆、手机、监控、设定展示 | E 花样 | 按需，不连用 |
| 双线、对峙、物件视角 | F 结构 | 按需 |

**三条硬约束：**
1. 连续两页不得使用同一种版式（哪怕都走 A 组，也要换编号）
2. B 组「燃」整册不超过 15%，否则读者视觉疲劳，高潮就不再是高潮
3. E 组「花样」不得连续两页使用，它靠稀有感起作用

## 四、提示词拼装规则

版式提示词 = **版式主句** + **通用尾巴**。

**通用尾巴（每个版式都必须带，保证出的是整页漫画而不是单张插画）：**

```
让该分镜机制决定页面结构、阅读顺序、主次画格和镜头节奏；
输出一张完整单页漫画页面，画格共同讲述连续情节，角色外观在各格保持一致。
```

英文版：
```
Let this storyboard mechanism determine page structure, reading order,
panel hierarchy and shot rhythm. Output ONE complete single manga page
where panels together tell a continuous scene, with character appearance
consistent across all panels.
```

**完整示例（A 组 SB-004 顶部大格开场）：**

```
漫画分镜。排版：顶部大格开场，用横跨页面的大面板建立场景和人物关系，下面再进入连续叙事。
让该分镜机制决定页面结构、阅读顺序、主次画格和镜头节奏；输出一张完整单页漫画页面，
画格共同讲述连续情节，角色外观在各格保持一致。
```

**与夜秣漫画生成器主流程的对接方式：**

主 SKILL.md 里的 7 种基础布局（竖排多格 / 左右两格 / 上二下一 / 上一下二 / 四格网格 / L型 / 混合）是**骨架**，
本库的 68 种是**骨架上的装饰与变体**。两者不冲突：

- 先用主流程决定「几格、什么骨架」
- 再用本库给这一页挑一个具体版式编号，决定「格子怎么切、视线怎么走」
- 输出时两个都要写：骨架提示词前缀 + 版式提示词
